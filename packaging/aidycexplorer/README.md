# AidyCExplorer

Explorador de archivos de AidyCOS.

- Lugares habituales (inicio, escritorio, documentos, descargas) y discos montados.
- Copiar, cortar, pegar, renombrar, carpeta nueva y papelera.
- `Super+E` abre el explorador. Las carpetas del sistema también lo usan.

```bash
aidycexplorer
aidycexplorer ~/Descargas
```
